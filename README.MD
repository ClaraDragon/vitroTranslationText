To translate:
    * The txt files contain duplicated lines, translate the second one. Be careful of the tags.
    * To add the file to the game for testing, it can be added internally while running it on debug and renaming the folder to:
        * Text_[language]_core
        * Text_[language]_game

        Then inside the game on the F9 menu select: "Compilar Texto" and picking the desired language, if option doesn't appear, create a folder called "Mods" and add the "language_support.rb" file from this repo. When compiling, the game will output format errors on the translation.
